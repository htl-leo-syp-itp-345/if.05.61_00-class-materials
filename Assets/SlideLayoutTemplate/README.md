# Slide layout references

The original editable [Keynote](SlideLayoutTemplate.key) and [PDF](SlideLayoutTemplate.pdf) are preserved here, together with the [paper background](template-paper.jpg) and numbered PNG references. [DESIGN.md](../../DESIGN.md) defines the visual rules; the [authoring guide](../../docs/slide-authoring.md) defines Markdown syntax and renderer support.

PNGs 01–07 show the original seven slide types. [08-speech-bubble-and-box.png](08-speech-bubble-and-box.png) adds component references for speech bubbles in gray, red, and amber, and a rounded box with 34 px corners. These are semantic callouts used within a slide type, rather than an additional slide type. The shared renderer implements them as editable shapes with editable text.
