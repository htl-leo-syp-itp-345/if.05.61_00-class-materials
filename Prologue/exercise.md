# Prepare for Episode 1

Prepare the tools and account you will use for the practical exercises. Complete this setup at home in preparation for Episode 1. If you already have a working installation or account, check that you can use it.

1. **Install Visual Studio Code.** Download it from the [official VS Code website](https://code.visualstudio.com/download), follow the instructions for your operating system, and open the application.
2. **Install Git.** Follow the [official Git installation instructions](https://git-scm.com/install/) for your operating system. Open a terminal in Visual Studio Code and run `git --version`. Check that it displays a Git version number.
3. **Create or access your GitHub account.** Follow the [GitHub account guide](https://docs.github.com/en/get-started/onboarding/getting-started-with-your-github-account) to create an account and verify your email address, or sign in to your existing account. Check that you can access your profile.

**Expected result:** Visual Studio Code opens, `git --version` works in its terminal, and you can sign in to your GitHub account. Repository creation and the first Git workflow remain part of Episode 1.
