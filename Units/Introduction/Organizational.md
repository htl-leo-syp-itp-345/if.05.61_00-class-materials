# Organizational

## Course Content

The course develops a background in software project development and basic project management skills. Topics include:

- What projects are and how projects are started
- Project organization, requirements management, planning, configuration management, quality assurance, methods, and tools
- Software development process models, including Waterfall, V-Model, RUP, and Scrum
- System specification: application-domain analysis, UML, functional and non-functional requirements, and client-server architecture
- Implementation: software design, UML, team coding, collaborative coding models, spec-driven and agentic programming, and test-driven development
- Testing strategies, plans, and protocols
- Releasing and deployment, including staging, production, virtualization, Docker files, and Docker images

The course combines theoretical background, including selected parts of the book, with practical exercises using smaller examples. Project work also involves planning and monitoring, version control, virtualization, and deployment, as well as documentation beyond source code, such as a project proposal, system specification, and UML diagrams.

## Project

The course project is a small, content-driven website. Each team should find a topic for its project.

Project work is collaborative, carefully planned, temporary, and directed toward particular tasks within time constraints. Project approval is based on the project's necessity, feasibility, affordability, and market and economic effect.

## Project Name

If you are not able to come up with a good project name go back, rethink your project idea and try again. A good project name is short, catchy and gives a hint what the project is about.

## Time to be Invested

The numbers of weekly hours in class is expected to be spent by every team member outside of class as well. This means if you have 3 hours of SYPPRE in class per week you personally should expect to spend another 3 hours per week outside of class for SYPPRE related activities like working on the project, reading material or preparing presentations.

Calculate the total time:

- 3 hours in class per week
- 3 hours outside of class per week
- makes 6 hours per week for 32 weeks a year
- equals 192 hours per year per team member
- for a team of 3 members this means 576 hours per year

**The message behind:** You have a real lot of time to work on your project. You can really **change the world with your product** if you want to.
