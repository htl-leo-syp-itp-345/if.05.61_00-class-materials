## Working website prompt

Use case: ui-mockup.
Create one polished, realistic screenshot image of the fictional Campus Café website for a teaching slide about version control. Output a square 2048 × 2048 px raster image, high resolution, crisp typography. It must immediately read as a real finished café website, not a slide or a diagram.
Show a straight-on desktop browser window filling the square frame, with a slim neutral browser toolbar, address campus-cafe.example, and a complete, well-composed website below. No monitor hardware, no perspective, no surrounding desk, no external margins.
Website identity: Campus Café. A warm welcoming café serving students. Clean readable dark typography, cream page background, restrained forest-green navigation and buttons. Use genuine photographic-looking café imagery: a large hero photograph of coffee and pastries on a café table, plus two small food photos below.
Exact prominent text: "Campus Café"; navigation "Menu" "Visit" "Contact"; hero headline "Good coffee. Good company."; supporting line "Your break between classes."; button "Explore the menu"; lower section title "Fresh from the café"; two menu items "Coffee & pastries" and "Lunch between classes".
Make the navigation a recognizable top horizontal website navigation bar, the hero professionally aligned and the lower food section aligned in a sensible grid. Use large enough type to recognize the website at slide size. Everything clean, aligned, functional, balanced, finished, naturally spaced. No Reservations link in this working original. No teaching annotations, no HTL logos, no slide bullets, no watermark.

## Broken website edit prompt

Keep the same square canvas dimensions, exact browser chrome and address, Campus Café identity, same coffee/croissant hero photograph and the same two lower food photographs. This is a CSS/layout regression, not damaged pixels.
Add the new navigation item "Reservations" prominently and legibly alongside "Menu", "Visit", "Contact" near the top: the newly added link must be easy to find.
Below that recognizable header, make the page obviously unusable and poorly styled: collapse the professional layout into awkward misaligned blocks, switch the hero headline to an excessively large default serif font and have it collide with the misplaced hero photo; turn the menu call-to-action into a default blue underlined link; make one lower food photograph too small and move the other awkwardly into the text flow; lose the neat two-column menu arrangement and padding. Preserve the original site's main words and photographic content so the before/after relationship is unmistakable. Keep "Reservations" readable and distinct from the broken content. The broken state must be visually unmistakable even at small slide size, not a subtly less polished redesign.
Maintain photographic realism within the screenshot. No cracking, glitch stripes, paint, error-message overlay, teaching annotations, slide text, or watermark. Show one complete screenshot only.
